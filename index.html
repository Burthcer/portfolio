IHatePDF
IHatePDF

      

        
Project 01 of 02
Web app + Windows desktop app · v1.3.1

        
Twenty-eight PDF tools that run inside your browser tab. Nothing is uploaded, because there is no server.

        

          Source code ↗
          Download for Windows ↓
          Full test report ↗
        

      


      

        
        
        
        
      


      

        

          

            
Merge, split, compress, convert, sign, redact, protect, and edit the actual text inside a PDF. The file is read into memory, processed with WebAssembly, and handed back to you. It also ships as a Windows desktop app that saves results straight to your Downloads folder.

  1. Edit text in placeDouble-click a paragraph and retype it. It reflows in the document's own font, and the old characters are removed from the file, not covered up.
    2. 
            
  2. Compress to a target sizeAsk for 2 MB and get it: a 35.5 MB scan came out at 1.95 MB, all on your machine.
    3. 
            
  3. Send to your phone, offlineShare files or whole folders over Wi-Fi, the PC's own hotspot, or Bluetooth.
    4. 
            
  4. Safe on low-memory PCsA memory fail-safe slows or stops a job before Windows runs out, instead of freezing.
    5.

Wisperno

Windows desktop app · CUDA · Python

        
Push-to-talk dictation for Windows that runs on your own GPU. Your voice never leaves the machine.

Hit the hotkey, speak, and clean text lands in whichever app has focus. Whisper large-v3-turbo transcribes on CUDA, then a local quantized LLM fixes filler words and punctuation. A free alternative to cloud dictation apps like Wispr Flow.

From BENCHMARKS.md, llama-cpp-python 0.3.26. Upgrading the engine from 0.2.90 made every preset 20 to 30% faster with the same VRAM.


Fidelity is measured on raw model output, before the app's own guardrail. In real use every transform goes through that guardrail, and all four presets pass the 5-prompt adversarial suite (prompts that try to make the model answer back instead of cleaning dictation) 100%. Every preset stays under the 5 GB system RAM budget with over 1.6 GB to spare.
The 600 ms hop is kept with over 2× margin even at the worst hop measured. An earlier sliding-window design was found by testing to silently drop words, so live mode now re-decodes the whole unconfirmed buffer every time.

02Ideas

      
Three rules I build by.

    

    
If it runs on my computer, it should work without the internet. Everyday tools shouldn't be a subscription. And the safest upload is the one that never happens.

    
    
      
  1. 1Ownership
    Works without the internet.
    Your documents and your voice belong on your machine. If a tool needs a connection to merge a PDF, the connection is there for the vendor, not for you.
    2. 
      
  2. 2Price
    No subscription.
    Build it once, own it forever. No monthly fee, no trial that runs out, and the source is open so anyone can check what it does.
    3. 
      
  3. 3Security
    No upload, no leak.
    A file that never leaves your laptop can't leak from someone else's server. Running offline removes whole categories of risk instead of patching around them.
    4.
